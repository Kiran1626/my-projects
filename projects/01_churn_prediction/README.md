# Customer Churn Prediction using Machine Learning

**Stack:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

Predicts which telecom customers are likely to leave, using customer profile and billing data.

## Run
```bash
pip install -r requirements.txt
python generate_data.py     # creates data/customer_churn.csv (7,000 synthetic rows)
python churn_model.py       # cleans data, plots EDA, trains and compares models
```
Outputs are saved in `outputs/`: `metrics.json`, `eda_churn_drivers.png`, `confusion_matrix.png`, `feature_importance.png`.

## What it does
1. **Cleaning:** converts blank `TotalCharges` to numbers, fills missing `MonthlyCharges` (median) and `TotalCharges` (monthly x tenure), drops duplicates and the ID column.
2. **EDA:** churn by contract type, tenure distribution, monthly charges vs churn.
3. **Modelling:** one-hot encoding and scaling in a scikit-learn `Pipeline`, stratified 80/20 split, Logistic Regression vs Random Forest.
4. **Evaluation:** accuracy, precision, recall, F1, ROC-AUC, confusion matrix, feature importance.

## Results (seed 42, 1,400 test rows)
| Model | Accuracy | Recall (churn) | ROC-AUC |
|---|---|---|---|
| Logistic Regression | ~0.76 | ~0.52 | see metrics.json |
| Random Forest | ~0.77 | ~0.51 | see metrics.json |

## Note on data
The dataset is **synthetic**, generated by `generate_data.py`. To use real data, download the Kaggle "Telco Customer Churn" CSV, save it as `data/customer_churn.csv`, and rerun `churn_model.py`. Say this clearly on your resume and in interviews.
